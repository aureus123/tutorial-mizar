Tutorial interactivo · Mizar 8.1.15 · MML 5.94

Mizar paso a paso

Diecinueve lecciones para aprender a formalizar matemática de grado en Mizar: lógica, igualdades y desigualdades, ecuaciones, conjuntos, funciones monótonas, límites, inducción y cardinales. En cada una lees un poco aquí y completas una demostración en VS Code.

Qué es Mizar

Mizar es tres cosas a la vez: un lenguaje para escribir matemática con todo detalle, un verificador que comprueba cada paso, y una biblioteca, la MML (Mizar Mathematical Library), con unos 1500 artículos ya verificados que van desde los axiomas de la teoría de conjuntos hasta el análisis y el álgebra.

Una demostración en Mizar se parece a la de un libro: «sea x…», «supongamos que…», «luego…», «por lo tanto…». No se dan órdenes a un asistente; se declara el razonamiento y el verificador decide si cada paso se sigue de los anteriores.

theorem
  for x being Real st 0 < x holds 0 < x/2
proof
  let x be Real;
  assume 0 < x;
  hence 0 < x/2 by XREAL_1:215;
end;

Debajo hay lógica clásica de primer orden y teoría de conjuntos. Encima, un sistema de tipos pensado para que las fórmulas se escriban como en la pizarra.

Cómo se usa este tutorial

  1. Lee la lección. El código de los ejemplos sale de artículos que se verifican con Mizar 8.1.15.
  2. Abre en VS Code el archivo que indica la sección Manos a la obra. Está en la carpeta text y le faltan renglones, señalados con comentarios :: EJERCICIO n:.
  3. Compila con Mizar Compile. Verás los errores que produce cada hueco.
  4. Completa los renglones y vuelve a compilar, hasta que no quede ningún error. Si te atascas, cada ejercicio tiene pistas y la solución; el archivo resuelto está en soluciones.
  5. Marca el ejercicio como hecho. El avance se guarda en este navegador.

Preparación

Hace falta tener instalado Mizar (con sus programas en el PATH y la variable MIZFILES apuntando a la biblioteca), Python 3 y VS Code con la extensión Mizar extension. El archivo README.md del tutorial explica cómo instalarlos. Después, comprueba que funciona:

Si no compila

Si VS Code avisa You have to set environment variable "MIZFILES", es que no heredó las variables de tu terminal: ciérralo y ábrelo desde una terminal donde la variable esté definida, con code tutorial-mizar. En Linux y macOS, la extensión necesita además que los programas de Mizar estén en el PATH.

La carpeta del tutorial

tutorial-mizar/ ├── README.md instalación y versiones ├── index.html esta página ├── text/ los artículos con huecos: aquí trabajas │ ├── t01_hola.miz │ └── … ├── soluciones/ los mismos artículos, completos y verificados ├── dict/ vocabularios: los símbolos nuevos de cada artículo ├── verificar.sh compila desde la terminal ├── mml.py busca teoremas en la biblioteca └── _fuentes/ de dónde se generan esta página y los ejercicios

La disposición no es casual. Mizar busca los vocabularios en una carpeta dict y la biblioteca local en una carpeta prel, ambas en el directorio de trabajo; la extensión de VS Code usa como directorio de trabajo el padre de la carpeta donde está el .miz. Por eso los artículos van en text (o en soluciones) y dict está al lado.

Al compilar, Mizar deja junto al .miz una veintena de archivos auxiliares con el mismo nombre y otras extensiones. Puedes ignorarlos.

Desde la terminal

Todo lo que hace la extensión se puede hacer también a mano, desde la carpeta tutorial-mizar (en Linux y macOS):

./verificar.sh t01_hola        :: compila text/t01_hola.miz y lista los errores
./verificar.sh -s t01_hola     :: lo mismo con soluciones/t01_hola.miz
./mml.py XREAL_1:215           :: muestra un teorema de la MML
./mml.py -g 'sqrt.*<=' SQUARE_1   :: busca teoremas por expresión regular
