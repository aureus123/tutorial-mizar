Funciones

Las funciones de la matemática son, en Mizar, objetos de la teoría de conjuntos. Aquí se aplican, se componen y se demuestra que la composición de funciones monótonas es monótona.

Son dos cosas distintas con nombres parecidos:

«x in REAL» y «x is Real»

Los teoremas generales sobre funciones hablan de conjuntos cualesquiera y por eso piden hipótesis de la forma x in X. Nuestras variables, en cambio, tienen tipo Real. El puente es XREAL_0:def 1 (ser real es estar en REAL):

theorem Comp: (g*f).x = g.(f.x) proof x in REAL by XREAL_0:def 1; hence thesis by FUNCT_2:15; end;

Cuando el teorema pide un Element of REAL (un tipo, no una fórmula), el puente es un reconsider:

theorem Suma: (f + g).x = f.x + g.x proof reconsider x1 = x as Element of REAL by XREAL_0:def 1; (f + g).x1 = f.x1 + g.x1 by VALUED_1:1; hence thesis; end;

Conviene demostrar estos pequeños lemas una vez, al principio del artículo, y citarlos después.

Funciones monótonas

Varios atributos se pueden definir en un mismo bloque:

definition let f be Function of REAL,REAL; attr f is creciente means :DefCrec: for x,y being Real st x <= y holds f.x <= f.y; attr f is decreciente means :DefDecr: for x,y being Real st x <= y holds f.y <= f.x; attr f is estr_creciente means :DefEC: for x,y being Real st x < y holds f.x < f.y; end;

Y ahora el teorema. La tesis g*f is creciente se despliega sola (la definición es del mismo artículo), así que la demostración entra directamente con let x,y;.

theorem f is creciente & g is creciente implies g*f is creciente proof assume that A1: f is creciente and A2: g is creciente; let x,y; assume x <= y; then f.x <= f.y by A1,DefCrec; then g.(f.x) <= g.(f.y) by A2,DefCrec; then (g*f).x <= g.(f.y) by Comp; hence (g*f).x <= (g*f).y by Comp; end;

Cada then hace una sola cosa: aplicar la monotonía de f, la de g, y reescribir un lado y luego el otro con el lema Comp. Se podrían juntar algunos pasos, pero así se lee igual que en el pizarrón.

Límites y continuidad

Las demostraciones épsilon-delta tienen una estructura fija, y esa estructura es exactamente el esqueleto que Mizar pide.

La definición

definition let f be Function of REAL,REAL, c be Real; pred f es_continua_en c means :DefCont: for eps being Real st 0 < eps ex delta being Real st 0 < delta & for x being Real st |.x - c.| < delta holds |.f.x - f.c.| < eps; end;

Fíjate en que for … st … ex … st … se escribe de corrido, sin holds antes del ex: es una abreviatura admitida.

Usar una hipótesis de continuidad

Cuando la continuidad es una hipótesis, se usa al revés: se le entrega un épsilon y devuelve un delta, mediante consider. En la composición g*f, el delta de g hace de épsilon para f:

assume that A1: f es_continua_en c and A2: g es_continua_en f.c; let eps be Real; assume 0 < eps; then consider d1 being Real such that A3: 0 < d1 and A4: for y being Real st |.y - f.c.| < d1 holds |.g.y - g.(f.c).| < eps by A2,DefCont;

El consider cita DefCont porque la hipótesis A2 está «plegada»: es el predicado es_continua_en, y hay que desplegarlo para ver el ex delta.

Para la suma de dos funciones continuas aparece el truco habitual: pedir eps/2 a cada una y tomar delta = min(d1,d2). El archivo de ejercicios lo trae casi completo, y termina con la relación entre continuidad y límite: f es continua en c si y sólo si su límite en c es f(c).

Más lejos

Con el mismo esquema se demuestran el límite de una suma y el teorema del sándwich para sucesiones; los dos son buenos ejercicios para hacer por tu cuenta. La MML tiene su propia teoría de límites (SEQ_2, LIMFUNC1, FCONT_1), más general y más trabajosa de usar.
